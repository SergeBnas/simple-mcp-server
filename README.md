# Simple MCP Server

A small MCP (Model Context Protocol) server in Node.js with three tools for a company handbook:

- `list_topics`: lists the handbook topics
- `search_handbook`: finds the entries that match a question
- `vacation_days_left`: calculates the vacation days left this year

## Run

```bash
npm install
npm start
```
